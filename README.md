# SHYAM KARUMURI Portfolio

Modern professional developer portfolio built with React + Vite + Tailwind CSS + Framer Motion.

## Features
- Dark modern UI with glassmorphism
- Fully responsive layout
- Animated hero and skill cards
- Project cards with hover effects
- Internship experience section
- Certifications, Education, Contact, Footer
- Smooth scrolling navigation
- Resume download
- Deployment ready for Vercel

## Tech Stack
- React
- Vite
- Tailwind CSS
- Framer Motion

## Run Locally
```bash
npm install
npm run dev
```

## Build for Production
```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this repository to GitHub.
2. Import the project in Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`
5. Output directory: `dist`
